Install the suite

Pick how you use Claude

Claude comes in a few forms. Choose yours below and follow the steps — no coding required. It takes about a minute either way.

The Claude desktop app and Claude in your web browser (claude.ai) use the exact same steps — everything here is point-and-click.

  1. Open Claude. Launch the Claude desktop app, or go to claude.ai in your browser and sign in.
  2. Open the plugins area. In the left sidebar, click Customize, then open the Plugins tab.
  3. Add SaaScend's marketplace. Under Personal plugins, click the + button, choose Add marketplace, then Add from a repository. Paste the address below and click Add.
    itisALLAN/revops-ai-readiness-plugin
  4. Install the suite. Back on the Plugins tab, click Browse plugins, find RevOps AI Readiness Suite, and click Install.
  5. You're ready. The /readiness, /activate, and /roadmap commands plus 25 skills now appear when you type / in a chat. Head to your first ten minutes below.

Using Claude Code in your terminal, IDE, or the Claude Code app? Copy each command and paste it into the prompt, one at a time.

  1. Add the SaaScend marketplace. Claude Code will ask you to confirm you trust the source — choose yes.
    /plugin marketplace add itisALLAN/revops-ai-readiness-plugin
  2. Install the suite.
    /plugin install revops-ai-readiness-suite@saascend
  3. Switch it on. Run /reload-plugins (or just restart Claude Code) to activate the suite.
    /reload-plugins
  4. You're ready. Type /readiness to begin — or jump to your first ten minutes below.

Prefer a menu? Run /plugin, open the Discover tab, select RevOps AI Readiness Suite, and install it there.

Don't see the /plugin command? Update Claude Code with npm install -g @anthropic-ai/claude-code@latest (or brew upgrade claude-code), restart it, and try again.

Or just ask Claude

Prefer to be guided? Once the suite is installed, paste this prompt into Claude Code and it'll take you from zero to your first deliverable.

I've installed the SaaScend RevOps AI Readiness Suite. Help me take my first safe step toward AI: ask me which GTM team to focus on (Customer Success, Sales, Marketing, or RevOps), tell me what data or public URLs I can share, then run the right readiness tool and walk me through the findings.

Before you start — two requirements

  • Claude Code with plugins enabled. Desktop, CLI, or IDE — any current Claude Code.
  • python3 on your PATH. The deliverable renderer uses only the Python standard library — nothing to pip install.
  • No credentials. No CRM/MAP logins, OAuth, or API keys. Inputs are file uploads, Google Drive, and public URLs via native Claude connectors.
