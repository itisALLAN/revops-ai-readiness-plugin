Install in Claude Code

Two commands

Run these inside Claude Code — copy each line and paste it in. The first adds SaaScend's plugin marketplace; the second installs the suite.

Step 1 — add the SaaScend marketplace
/plugin marketplace add itisALLAN/revops-ai-readiness-plugin
Step 2 — install the suite
/plugin install revops-ai-readiness-suite@saascend

Prefer a menu? Run /plugin, open the Discover tab, and install RevOps AI Readiness Suite from there. Either way, the 25 skills and the /readiness, /activate, and /roadmap commands become available immediately.

Or just ask Claude

Prefer to be guided? Once the suite is installed, paste this prompt into Claude Code and it'll take you from zero to your first deliverable.

I've installed the SaaScend RevOps AI Readiness Suite. Help me take my first safe step toward AI: ask me which GTM team to focus on (Customer Success, Sales, Marketing, or RevOps), tell me what data or public URLs I can share, then run the right readiness tool and walk me through the findings.

Before you start — two requirements

  • Claude Code with plugins enabled. Desktop, CLI, or IDE — any current Claude Code.
  • python3 on your PATH. The deliverable renderer uses only the Python standard library — nothing to pip install.
  • No credentials. No CRM/MAP logins, OAuth, or API keys. Inputs are file uploads, Google Drive, and public URLs via native Claude connectors.
