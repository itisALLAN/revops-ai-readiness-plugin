Install in Claude Code

Two commands

Run these inside Claude Code. The first adds SaaScend's plugin marketplace; the second installs the suite.

# 1 — add the SaaScend marketplace /plugin marketplace add itisALLAN/revops-ai-readiness-plugin # 2 — install the suite /plugin install revops-ai-readiness-suite@saascend

Prefer a menu? Run /plugin, open the Discover tab, and install RevOps AI Readiness Suite from there. Either way, the 25 skills and the /readiness, /activate, and /roadmap commands become available immediately.

Before you start — two requirements

  • Claude Code with plugins enabled. Desktop, CLI, or IDE — any current Claude Code.
  • python3 on your PATH. The deliverable renderer uses only the Python standard library — nothing to pip install.
  • No credentials. No CRM/MAP logins, OAuth, or API keys. Inputs are file uploads, Google Drive, and public URLs via native Claude connectors.
Where to begin

Your first ten minutes

Pick the path that matches what you have on hand. You can run everything on built-in sample data first if you'd like to see the output shape.

Fastest win

Codify your brand

Run /activate brand-codex with a few blog URLs. You'll get a reusable brand codex other tools build on — a quick, satisfying first artifact.

By team

Run a readiness pass

Run /readiness and pick a team. Upload the matching export (cases, opportunities, or leads) and get an actionable fix list.

The big picture

Synthesize a roadmap

After a few team tools have run, /roadmap traces every symptom back to its root RevOps cause and ranks what to fix first.

★

Recommended starting move

Run a readiness tool for the team feeling the most AI pressure today (often Customer Success or Sales), act on the top blocking finding, then come back and run /roadmap to see how that fix fits the whole org. Every output tells you exactly what to change — and you own each action.
